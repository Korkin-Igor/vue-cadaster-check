# Vue Cadastral Check 🏠

**Vue Cadastral Checker** — это веб-сервис для собственников недвижимости, позволяющий проверить корректность кадастровых данных перед государственной оценкой. Инструмент помогает выявить ошибки в характеристиках объектов и предотвратить завышение налога на имущество.

## 🎯 Проблема и решение

В 2027 году (и далее по графику регионов) проходит государственная кадастровая оценка. Ошибки в данных (площадь, назначение, материал стен) ведут к переплатам по налогам на 4 года вперед.

**Сервис позволяет:**
- Проверить актуальность данных объекта в реестре.
- Получить пошаговую инструкцию по подаче декларации об уточнении характеристик.
- Минимизировать риски налоговых переплат через МФЦ или Госуслуги.
